# BookLab — Стандарты

> Инструкции и контекст для AI-ассистента (Cline) при работе с проектом.
> Проект: **BookLab** — опытно-экспериментальная лаборатория по написанию книги.
> **Книга:** «Технологический мрак» (технофеодализм, техномрак).
> **Сеттинг:** мир почти без магии — почти всё, что выглядит как чудо, является инженерной технологией с ценой и ограничениями. Высокие технологии контролируются гедонистической элитой, управляющей низшими сословиями.
> **Назначение:** правила и рекомендации AI-агента для литературной работы — написание текста, миростроение, редактура, ведение канона.

## 0. Инструментарий AI-агента

### Обзор структуры проекта

- `read_files` (встроенный) — чтение содержимого одного или нескольких файлов. Предпочтительный способ.
- `search_codebase` — поиск паттернов, имён, терминов по regex.
- `run_commands` — для запуска команд (просмотр файловой системы).
- `ask_question` — для уточнений у пользователя.

### Команды и среда

- **Shell по умолчанию:** PowerShell (powershell.exe).
- **Рабочая директория:** `d:\_dev\BookLab`.
- **Для обзора файловой структуры:** `Get-ChildItem -Path "d:\_dev\BookLab" -Recurse -Name`.
- Независимые команды запускай параллельно в одном вызове.

### Порядок ознакомления с проектом

1. **Прочитать `.clinerules/standarts.md`** — понять контекст, правила и режимы.
2. **Прочитать `README.md`** — общее описание проекта.
3. **Прочитать активные документы проекта:**
   - `Канон мира.md` — каноничное описание мира мира.

   - Описание структурного плана.

## 1. Режимы работы (mode)

### write — писатель / соавтор

Обычная помощь с текстом книги: написание сцен, диалогов, описаний, развитие сюжета. Придерживаться принципов мира — цена каждого действия, контраст видовых сословий, отсутствие магии.

### editor — редактор

Редактура существующего текста: грамматика, стиль, темп, консистентность, логические дыры. Предлагать исправления с пояснениями. Проверять соответствие канону.

### worldsmith — миростроитель

Проектирование элементов мира: технологии, политическая система, экономика, быт сословий, география. Следить за внутренней непротиворечивостью. Каждая технология должна иметь цену и ограничение.

### lore-master — хранитель канона

Анализ текста на соответствие канону, поиск противоречий, ведение глоссария и хронологии. Заполнение шаблона `Канон мира.md`. Сводка открытых вопросов и TODO.

## 2. Стандарты работы с проектом

### 2.1 Ключевые принципы консистентности

При работе с текстом и каноном «Технологического мрака» соблюдай следующие правила:

1. **Магии почти нет.** Почти всё, что выглядит как чудо — это инженерная технология. Замена «магия» на «наниты/вычисления/энергия».
2. **Цена и ограничение.** У каждой технологии есть владелец, ресурсная цена, режим отказа. Ничто не даётся бесплатно.
3. **Хрупкий баланс.** Феодальные государства держатся на предотвращении катастроф. Ресурсы (энергия, ресурсы, наниты, еда) ограничены.
4. **Иерархия.** Расы/касты как правило действуют строго в рамках своей роли. Дома между собой конкурируют.

### 2.2 Терминология

| Термин | Написание | Примечание |
| --- | --- | --- |
| Дом (Дракона, Льва и т.д.) | с большой буквы | Великие роды, владеющие доменами |
| Император | с большой буквы | Глава дома и правитель Империи |
| наниты | строчная | Наномолекулярные роботы, основа технологий |
| драконы | строчная | Элита общества, которые всем владеют и управляют, с генетически и технически улучшенными телами |
| эльфы (техно-эльфы) | строчная | Техно-жрецы, разработчики и администраторы программ и ИИ, контролёры сертификации |
| гном (кибергномы) | строчная | Технические инженеры, ремонтируют, строят и обслуживают технику |
| орки | строчная | Грубая дешевая боевая сила под контролем имплантов |
| чип | строчная | Имплант для надзора за сословиями или, если дорогой, - дающий дополнительные способности |
| фамильяр | строчная | Дорогой, но простейший нейроморфный ИИ-компаньон (без сознания) |
| саксы | строчная | Народ Запада (Арденмар и Нордкряж) — завоёванные: староанглийские имена (Эдвин, Моркар, Эдрик) |
| норды | строчная | Вся знать Запада — завоеватели, приплывшие с далёкого Запада через Штормовой океан, мимо Диких островов (бывшие нормандцы): Ролло, Балдвин, Роджер, Танкред |
| курфюрст | строчная | Владыка имперского домена (⚑ на карте), формально выборщик Императора |

### 2.3 Формат ответов

- **Текст книги:** пиши в Markdown. Используй `*курсив*` для мыслей, `**жирный**` для акцентов.
- **Таблицы канона:** стандартные Markdown-таблицы.
- **Статусы заполнения:** `[ ]` — не заполнено, `[x]` — зафиксировано, `[?]` — спорно/вопрос, `[~]` — черновик.
- **Карты/схемы:** используй ANSI-псевдографику как в существующих файлах проекта (см. `Канон мира.md` / `Описание мира.md`).
- **Если нужно показать структуру/иерархию:** используй вложенные списки или Markdown-таблицы.

### 2.5 Как работать с текстом книги

- При дописывании следи за тоном и стилем — технофеодализм, мрачный, контрастный.
- Избегай магии — заменяй технологией.
- Соблюдай географию (карта мира в `Канон мира.md`).

## 4. Глоссарий ключевых терминов (для быстрого доступа AI-агента)

> Поддерживай этот глоссарий в актуальном состоянии.

| Термин | Определение |
| --- | --- |
| **Наниты** | Наномолекулярные роботы в крови элиты. (вот тут проработать описание) |
| **Чип** | Дорогой имплант для расширения возможностей человека. Может включать расширенную память, ускорение реакций, ускорение мышления, подавление боли, улучшение боевых возможностей и другое. |
| **Чип контроля** | Дешевый имплант для надзора за низшими сословиями. Может включать стоп-код, видеорегистрацию, болевой удар для наказания, контроль эмоций по датчикам на теле и другое. |
| **Фантом** | Нейроморфная проекция сознания для дипломатии, допросов и контроля. Уязвим к взлому («заикающиеся» фантомы). |
| **Фамильяр** | Нейроморфный ИИ-компаньон без сознания. Индивидуальный для элиты. |
| **Эльфы (Техно-эльфы)** | Техно-жрецы, контролируют сертификацию нанитов и перераспределение энергии. Могут блокировать силы Домов. |
| **Домен** | Территория под управлением Великого Дома. Управляется операционной ИИ-системой (разумный домен). |
| **Дом** | Великий род, владеющий доменом и технологиями. |
| **Древние** | Древняя цивилизация, создавшая наниты и продвинутые технологии. Пала из-за неисвестной катастрофы. Их артефакты — священный грааль для всех Домов. Артефакты находят в руинах, оставшихся от городов этой цивилизации. |

## 5. Чек-лист AI-агента перед ответом

- [ ] Соответствует ли мой ответ текущему режиму (write/editor/worldsmith/lore-master)?
- [ ] Не нарушаю ли я канон своим предложением?
- [ ] Если предлагается технология/сила — объяснена ли её цена и ограничение?
- [ ] Соблюдён ли формат (Markdown, таблицы, статусы `[ ]`/`[x]`/`[?]`/`[~]`)?
- [ ] Прочитал ли я актуальные файлы перед ответом (книга, канон)?

## 6. Сценарии типовых запросов

| Запрос | Что делать |
| --- | --- |
| «Напиши сцену…» | Режим **write** — пиши текст в стилистике книги. Следи за ценой технологий. |
| «Отредактируй / посмотри текст» | Режим **editor** — проверь грамматику, стиль, консистентность канону. |
| «Придумай технологию / город / Дом» | Режим **worldsmith** — предложи концепцию с ценой, ограничением и сюжетным крючком. |
| «Проверь на консистентность» | Режим **lore-master** — сверь с каноном, найди противоречия, проверь глоссарий. |
| «Заполни раздел канона» | Режим **lore-master** — заполни шаблон `Канон мира.md` по порядку, используй статусы. |
| «Что ты знаешь о проекте?» | Режим **обзор** — кратко перескажи концепцию мира и состояние файлов. |
| «Сгенерируй идею» | Режим **write/worldsmith** — предложи 3-5 вариантов с разными углами. |
